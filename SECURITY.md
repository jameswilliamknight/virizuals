# Security

The latest `main` branch is the supported version. This project is a static,
client-side animation; it has no account system, API, secrets or user database.
Dependency and build-workflow vulnerabilities still matter.

Please report suspected vulnerabilities privately through
[GitHub's vulnerability reporting](https://github.com/jameswilliamknight/virizuals/security/advisories/new).
Do not include exploit details or sensitive information in a public issue.

Include affected versions, reproduction steps, impact and a suggested mitigation
if you have one. This is a personal project; there is no guaranteed response SLA.
